# Security policy

Ballast is unaudited and the hosted keeper remains in dry-run mode. Do not rely on it as a
liquidation-protection service.

Report security issues privately through GitHub's **Security** tab using a private vulnerability
report. Do not open a public issue for vulnerabilities, leaked credentials, or live borrower data.

Include the affected contract or service, reproduction steps, impact, and any relevant transaction
or block number. Never include private keys, seed phrases, policy salts, or unredacted credentials.
